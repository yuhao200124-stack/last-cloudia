# 攻击力单标签核对与独立页面

## 用户最新要求

每次只处理一种标签。新增独立导航页面“技能列表打标签用的”，不是在原基础属性页再加一个小分组。本轮只重新处理攻击力，扫描范围是全部技能，不限于已有基础属性记录。

## 本轮范围和核算

- 以当前全库为范围：主表933项，分类页独有2项，共935个唯一技能。按URL优先去重，保留主表的稳定ID。
- 已逐条核对935条效果与已有补充说明：88条关键词候选 + 其余847条逐条复核。
- 攻击力相关87个：保留原基础属性中全部78个攻击力技能，新增9个关联技能。其余848个本轮不纳入。
- 新增9个：斗智转轮、惊喜礼物、攻击下降回避、作战行动、畏怖眼光、星之所在、信仰、强力治愈、适应驱动。
- “信仰”原文本身没有攻击力关键词，通过原库中“神秘之力【武威】”关联到攻击力+10%。原技能和提供效果的技能分别记录，不推导为可重复叠加的两份数值。
- 完整判断29个，判断部分58个，未识别0个。这里指本轮标签覆盖整条技能效果的程度，不代表所有数值机制都已接入计算。

“攻击力”包含明确的攻击力数值变化、武器本身攻击力变化、攻击力参照／比较／选人、攻击力下降保护、该次伤害计算的攻击力修正、明确技能引用转入效果。后几种写明关联用途，不当作攻击力百分比加成。

不因“攻击伤害”“物理伤害”或名字里出现“力量”就贴攻击力标签。名称命中的“这就是力量！”、“无法抗拒的力量洪流”均排除。英雄之血、狂战士等是伤害加成而非攻击力加成；激怒耐性属于异常耐性，不沿所有间接影响无限展开。

## 单标签覆盖原则

- 此页面的assignedTags只允许“攻击力”；不继承之前基础属性页的HP、法强、防御等完成状态，也不增加其他已贴标签。
- “攻击力、HP+10%”本轮只完成攻击力，HP留在待判断效果，整体为判断部分。
- “类型追加龙、攻击力+10%、物理减伤15%”本轮只完成攻击力，剩下两段分别列出。
- HP阈值、开场、武器要求等保留在攻击力效果说明内作为必要条件，不新建其他标签。
- 未确认动态数值继续保留计算备注。判断完成不意味着把生命鼓舞直接算成最高50%，或把所有Buff叠加。

## 原站集成

新页面为dist/skill-labeling.html，入口加入技能表、角色列表和伤害计算器导航。保持原站，原表、原SC、来源、数值规则和已存配装不重建、不重置。

表格仅四列：技能名称、判断、技能效果／说明、标签／判断说明。无SC、获得方式、评价和添加列。只在判断文字上使用黑色“已完整判断”、蓝色“判断部分”、红色“没办法判断”；其他表格文字黑色、全白底、内容直接展开。

排列顺序按用户补充要求固定为：已完整判断 → 判断部分 → 没办法判断。同一状态保留原全库技能顺序，搜索结果保持同样排序。

读取现有用户自定义名称和描述；描述变化则停用旧标签并列为待重新核对。被排除技能的自定义描述变化也返回待核对列表，防止用户已把内容改为攻击力效果却继续沿用旧排除结论。不写入或改动浏览器原保存数据。

## 维护文件

- docs/attack-tag-registry.json：87条人工核对记录、攻击力关联用途、未处理效果片段和原数字规则引用。
- docs/attack-tag-audit.json：覆盖全部935条的纳入／排除记录，以及原ID、URL、名称、效果、补充说明指纹。
- scripts/build-attack-tags.mjs：全库穷尽性、原文、单标签、已知78条不遗漏及技能引用检查。新增技能或原文变化须重新复核，不能静默沿用原统计。
- dist/attack-tag-catalog.mjs：供新页面读取的生成数据。numericEffectInjection=false，标签本身不重复注入数值计算。

此轮未开始类型追加、HP等下一标签。下一轮同样从全库找齐，按稳定ID复用技能与效果记录。

验证：17项相关功能检查通过，覆盖全库核算、单标签限制、复合技能待判断片段、间接引用、用户编辑保护、页面启动与搜索、旧表和配装数据保留。静态资源和导航链接已核对。本轮未进行真实浏览器视觉测试。
