# Buff 与条件：用户确认的后续接入规则

2026-09-24 用户根据 IMG_0611 / IMG_0612 截图纠正：

- 战斗开始获得是 Buff，截图快速鼓舞持续40秒；永久获得也是 Buff，只是无固定到期时间。二者不应作为未知基础属性而完全不接入。
- 濒死是条件，与满血、暴击等放在同一战斗选项区。当前满血与濒死互斥，未满血不自动等于濒死。
- 必须确认加成的计算方式。攻击力/法强 Buff 进入实时属性层；伤害提升进伤害规则；固定HP不能当成百分比。不能因为用户把效果口头称为“伤害”就改变原描述的属性类型。
- 同一类型 Buff 同时只计一项，不能把开场版、永久版或同组更强状态直接相加。

## 本次落地

24 个基础属性 Buff 从待确认改为已接入。分类仍为181个不同技能；已接入134、部分接入2、待确认45。

在原满血/暴击栏加入：濒死（HP≤30%）、开场Buff（40秒内）、觉醒Buff（触发后40秒）、魔导觉醒Buff（触发后40秒）。这些开关表示当前状态，**不是自动计时器，也不模拟整场战斗**。只影响已经选装、且未被删除或停用的技能。

激昂属于连续濒死被动。觉醒、魔导觉醒属于一次触发后的40秒状态，每Wave最多一次；回复使HP离开濒死范围后，已触发Buff仍可能存在。不能用同一个濒死开关同时控制这两种生命周期。觉醒的回血及移动效果继续作为未接入的其它类型提示。

不是根据“同一个属性”就把所有被动合并。满血、濒死的连续属性被动保留其独立实时分组。

辅助核对：
- https://altema.jp/lastcloudia/singekisinki ：Fast / Auto 同名魔法 Buff 不重复。
- https://altema.jp/lastcloudia/qa-item/227 ：相同状态组的普通/高阶/更高数值取当前有效的最高值。这是攻略问答依据，不冒称原生实测。

只有这些已标记为 `resolution: highest` 的标准状态组自动取高。其它未确认分组继续要求明确选择，不扩散该规则。用户明确选择的魔术指导继续按原规则替换EX增益。

每条状态规则含 layer、stackGroup、stackPolicy、resolution、lifetime 与依据；保存/导入有字段校验。固定活力进入实时固定加值，不参与基础属性百分比放大。

## 验证重点

20%限时 + 20%永久仍是20%；35%限时 + 20%永久为35%，关闭限时后回到20%；20%濒死被动 + 50%觉醒标准Buff为实时70%，回血后只保留50%。

基础1000 + 常驻15% 得1150，再加20%实时Buff得1380，不额外再乘一次“伤害+20%”。基础HP1000、常驻20%、永久活力1000，结果为2200，不是2400。

额外覆盖条件互斥、保存恢复、读取面板解释、同组同值去重、效果删除不恢复、未选装技能不因开关凭空生效，以及魔术指导替换EX的旧回归检查。真实浏览器预览当前不可用；不把DOM模拟测试描述为浏览器实测。

## 后续补充：现实时间、槽状态与事件触发

用户进一步确认：玛娜的节日、强力反击是条件属性加成，不是Buff；黄泉之理属于复活Buff；万圣节派对属于使用必杀触发的Buff；复仇鼓舞属于受伤Buff，条件栏只显示“受到伤害时”，不设概率输入或概率折算。

| 技能 | 条件字段 | 分类及已接入属性 |
|---|---|---|
| 玛娜的节日 | realSunday | 现实周日条件；攻击力、法强、防御力、魔抗+5% |
| 强力反击 | ultimateGaugeFull | 必杀槽满条件；攻击力+30% |
| 复仇鼓舞 | damageTakenBuffActive | 受到伤害时；攻击力Buff+20%，40秒 |
| 万圣节派对 | ultimateUsedBuffActive | 使用必杀后；防御力、魔抗Buff+20%，HP上限+1,000，40秒 |
| 黄泉之理 | reviveBuffActive | 复活后；攻击力、法强Buff+30%，40秒 |

前两者的缓存 effectCodes 为 Update STR/INT/DEF/MND、isBase=false，没有 Apply Buff。它们进入实时属性计算层，但明确标记 `runtime.kind=conditional-passive`，`stackPolicy=add`，`lifetime=condition`，使用独立组。现有底层 `statBuff` 数值容器表示实时属性层，不等于把所有条件属性都当成可覆盖的魔法Buff。学习规则验证禁止把 conditional-passive 改成 exclusive。

因此基础攻击力1000、周日5%、必杀槽满30%、自动鼓舞20%为1550。复活Buff30%替换鼓舞20%后为1650。不能把条件加成吞掉，也不能把两组实时加成错误乘成1000×1.35×1.2。

后三者沿用已有标准Buff组，并按当前有效的最高值只计一项。HP的固定1,000沿用实时固定加值；不会因为同时有自动活力再加一遍。勾选表示当前Buff有效，关闭表示失效；不模拟触发次数、概率、计时和复活过程。复仇鼓舞原始技能描述保留资料事实，但条件选项严格使用用户要求的简洁名称。

现实周日由用户按游戏设备时间手动选择，不擅自采用浏览器时区。必杀槽满与使用必杀后Buff独立：前者表示当前槽状态，后者表示先前触发且仍在持续的Buff，可能在持续期内再次充满必杀槽。

万圣节派对的SCT恢复速度+25%、黄泉之理的暴击率+15%均在原说明/待接入片段中明确保留，仍待对应分类处理，本次不混入六维属性或当成直接伤害加成。
