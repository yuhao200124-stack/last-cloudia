# 配装：在技能分类页配装（2026-09-29）

## 用户要求
- 先前的做法：计算器里点“配装”进入配装工作区，左边是游戏数据技能表（每行“+”），右边是结果和配装面板。
- 用户后来要求：“把新版本的配装删了改成在这个页面配装”，“这个页面”就是技能分类页（`skill-classes-preview.html`）。
- 用户的选择：
  - 分类页自己就是配装页。
  - 入口两种都要：从计算器点“配装”跳过去；在分类页上自己选角色。
  - 招式、目标、开关、命中数、专武这些战斗设置，在分类页上点“战斗设置”展开改。
  - 原来配装面板里的东西（每个技能的收益明细、角色专属 0 SC、自带被动开关、一二三破、保存／载入配装、推荐），在分类页上点“配装详情”展开。
  - 打开配装时，分类页的“属性 × 攻击”筛选自动选成当前招式的，还能手动改。

## 怎么用
1. 进入配装，三种方式任选：
   - 在分类页上方“配装”下拉菜单里选角色；
   - 在计算器里点“配装”（计算器在角色页的面板里也一样），会带着这个角色打开分类页；
   - 在角色页“已保存配装”里选一套，点“在配装页打开”。
2. 上方一行显示：
   - 招式（属性 · 攻击种类）；
   - 已选几个技能、SC 合计（哪个破免了哪个技能）、角色专属几个；
   - 当前配装每次伤害，以及和配装前（只有自带）比高多少。
3. 表格最右边多一列“配装”：点“+”加入，变成“✓”，下面显示这个技能的收益；再点一次取消。手机上这一列固定在右边。
4. “战斗设置”：展开计算器本身（招式、专武、开关、目标、结果卡）。改了会马上重算。
5. “配装详情”：展开原来的配装面板：
   - 自带被动开关（专武、个性、固有免费被动、超越、加护）；
   - SC 合计与一破／二破／三破；
   - 每个技能的收益和具体变化（去掉它伤害少多少、它改变了哪些数值），角色专属技能固定在下面（0 SC）；
   - 恢复角色推荐配装、从配装报告载入、重算全部收益、清空所选；
   - 保存／另存为新配装、已保存配装的载入／改名／删除；
   - 按每 SC 收益推荐。
6. “退出配装”：回到只看分类的样子。
7. 招式换了，“属性 × 攻击”会自动跟着换（普攻算“物理”）。

## 实现
- 分类页在一个框里打开计算器：`damage-calculator.html?character=<角色>&embedded=build[&plan=<配装>]`。
  - 框收起时还在后台计算（不用 display:none，用高度 0）。
  - 计算器 → 分类页（`lc-build-state`）：已选、角色专属、每个技能的收益、SC 与突破、每次伤害、配装前、招式（名称、第 1 击属性、技能类型）、是否在计算。
  - 分类页 → 计算器：`lc-build-toggle`（点了“+”）、`lc-build-view`（显示战斗设置还是配装详情）、`lc-build-hello`。
- 计算器单独打开（不在分类页的框里）时不按配装计算，配装面板不显示，“配装”按钮跳到分类页。
- 删掉的：计算器里的配装工作区（左边技能表框、工具栏、宽窄屏切换）、首页技能表的“+”模式（`index.html?embedded=1`）。
- 配装的规则没变：SC 与能力盘突破（`dist/build-sc.mjs`）、角色专属 0 SC、收益算法（去掉它伤害少多少，随机 0.95、只比第一条伤害弹道）、保存的配装格式（`lc-engine-plans:v1`）。
- 角色列表来自 `docs/site-characters.json`，由 `scripts/build-skill-classes.mjs` 写进分类页的数据。

## 核对
- 浏览器实际走了一遍（电脑、手机宽度）：
  - 选角色、点“+”（收益显示、SC 突破）、在配装详情里点“×”移除、保存配装；
  - 从计算器（包括角色页面板里的计算器）点“配装”跳过来；
  - 在角色页“已保存配装”里打开一套；
  - 换角色、退出配装；招式的属性和攻击种类自动选好筛选；
  - 首页技能表没有“+”，照常显示。
- 没有页面报错。
- 测试：`tests/build-workspace.test.mjs`。
