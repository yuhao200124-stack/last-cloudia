# 配装工作区：技能表选技能，计算器算加成（2026-09-29）

## 用户要求
（2026-09-29 后来：用户试过把配装改到技能分类页，又决定恢复这里的做法——配装从角色页进来，先确认角色，再配装。之后又决定：点“配装”不留在计算器里，**整个窗口回到首页**，还是左表右结果。）
把配装和计算器连起来：
- 配装之前先把计算器现在显示的内容算好。
- 在技能表里点“+”选一个技能，计算器自动算出这个技能带来多少加成。
- 和旧配装器一样，到主页面的技能表里去选。

用户确认的做法：
- 从游戏数据技能表选；并排显示，像旧配装工作区，手机上上下切换。
- 只在点“+”时计算，不要“试算”。
- 显示伤害提升百分比和具体变化。
- 角色自带、但技能表里没有的 SC 技能：“直接显示已经添加了，但是费用要改成0排列在最下面”。
- SC 合计和能力盘突破（7／12／20）都要。
- 原来的配装面板并进工作区，去掉搜索添加。
- 首页（单独打开的技能表）只供查看，没有“+”。

## 怎么用
1. 角色页 → 计算器 → 点“配装”（结果卡下面）：整个窗口换到首页 `index.html?character=角色编号`。
   - 左边是首页的游戏数据技能表（原来的样子），每行最右边有“+”。
   - 右边是计算器（`damage-calculator.html?character=…&embedded=build`，放在页面里的小框），显示结果和配装面板。
   - 单独打开首页（没有 `?character=`）时只供查看，没有工具栏也没有“+”。
2. **工具栏**（技能表上面）：
   - “技能表／战斗设置”切换左边显示技能表，还是计算器的招式、开关、目标（这时计算器占满整行）；
   - “收起结果”：把右边收起，技能表占满整行；
   - “退出配装”：回到这个角色的角色页。
   - 工具栏上显示角色名、已选数、SC 合计、当前配装每次伤害，和刚加入的技能的收益。
3. **加技能**：点“+”加入，按钮变成“✓”，下面显示收益；再点一次取消。每次加减都会重新计算。计算器还没准备好时“+”是灰的。
4. **手机**（窄于 900px）：工具栏是“技能表／战斗设置／结果与配装”三选一。技能表的“+”这一列固定在右边，左右滑动表格时也看得到。
5. **页面之间的消息**：计算器 → 首页 `lc-damage-ready`、`lc-build-state`；首页 → 计算器 `lc-build-toggle`（加／取消）、`lc-build-view`（显示结果还是战斗设置）、`lc-build-hello`。配装只在这个小框里算（`build.on` 只有在 `embedded=build` 时才打开），单独打开计算器时主结果不变。

## 配装面板
- **启用**：在首页配装时，主结果按配装计算。
- **自带被动**（2026-09-29 用户：“直接把这里头的内容都删掉，除那个专武都默认开启，专武由伤害计算器那个页面决定”）：
  - 配装面板里不再有说明文字和开关；个性、固有免费被动（能力盘上 SC 99 的）、超越、加护永远都算。
  - 专武按计算器自己的“专武”选项（未装备／某一件／全部／其他），和角色页里的计算器是同一个设置（按角色存在浏览器里），在首页配装时可以在“战斗设置”里改。配装面板的说明行写出当前的专武。
  - 保存的配装不再记专武和自带开关；以前存的这两项不再使用。
- **SC 合计与能力盘突破**：
  - 一破／二破／三破可以分别开关，默认全开。
  - 规则与旧技能表完全相同（`dist/build-sc.mjs`）：按 7、12、20 的顺序，每个打开的突破让 SC 不超过它的已选技能里、SC 最高的一个免费。
  - 免费的技能显示“0　一破（原 7）”这样。
- **每个技能的收益**：
  - 算法：去掉这个技能后，伤害会少多少（当前配装每次伤害 ÷ 去掉它后的每次伤害 − 1）。
  - **具体变化**：比较有它和没有它时本招式第 1 击实际吃到的数值，只列出变了的项：
    - 法强／攻击力、暴击率、伤害上限；
    - 特攻倍率、核心前倍率（攻／受／减伤）、属性抗性；
    - 核心后修正、暴击伤害倍率。
  - 没有任何变化时写“本招式没有变化”。
  - 计算顺序：先算刚加入的技能，然后是其他已选技能，最后是角色专属技能。
  - 都按随机 0.95、第一条伤害弹道比较，和结果卡的“每次期望”一致。
- **角色专属（0 SC，固定在最下面）**：
  - 什么技能算：角色能力盘上要花 SC、但不在游戏数据技能表里的技能。
    - 洛琪希：月光II、冰魔法暴击・改、自动速咏、贯导、杖神阶增幅、魔导提升极、法袍神阶增幅。
    - 艾莉丝：刚坚提升IV、服装神阶增幅、斗志提升极。
    - 梅莉：偏执狂、麻痺研究、生态研究、女神的神徒、斗志提升极、觉醒II。
    - 阿尔克：磊落II、真・二刀流。
  - 它们永远算在配装里，不能移除，也有自己的收益行。
  - 能力盘上、技能表里有的 SC 技能（例如洛琪希的暴击提升III）和其他技能一样，用“+”选，照常花 SC。
  - 判断依据：技能表的编号清单，由 `scripts/build-game-skill-table.mjs` 生成 `game-data/engine/table-passives.json`。
- **配装前（只有自带）**：没有选任何技能时的每次伤害，以及当前配装比它高多少。
- **保留的功能**：保存／另存／载入／改名／删除配装、恢复角色推荐配装、从配装报告载入、重算全部收益、清空所选、按每 SC 收益推荐。
  - 保存的配装多了突破设置；以前存的没有这一项，按三个都开。
- **去掉的功能**：搜索添加、候选按钮上的“试算”、推荐里“只算搜索到的被动”（依赖搜索框）。

## 角色页“已保存配装”
- SC 按同一个规则算，免费的写明是哪一破。
- 角色专属技能列在最下面，0 SC。
- 按钮叫“打开配装”：打开首页 `index.html?character=…&plan=…`，载入这套配装。
