# 计算器长期规则

## 2026-09-24 用户确认：同类型 Buff 只保留一份

魔术指导的法强 +65% 会替换同组原有的法强 +50%（EX 灵气），不能得到 +115%。
这是用户明确确认的机制，不再保留“指导与 EX 相加”的试算分支。

- 替换按效果所属 Buff 组判断，不按“都增加法强”判断。
- 月光II的满血条件属性是独立被动，仍按满血条件判断；它不会随 EX 被替换。
- 技能内攻击修正是技能参数，不属于这个 Buff 互斥组。
- 魔法上限是单独效果，按来源防止重复计入。
- 不推广为“所有 Buff 永远取最大值”；当前明确启用的同组 Buff 替换原组，其他胜出规则需各自依据。
- 观察面板已包含所选 Buff 时，复用其状态，不再次乘算或叠加。

## 通用引擎与专属资料分开

通用层负责面板与装备计算、Buff 分组替换、属性层、技能参数、攻防与抗性、伤害加成、上限、暴击以及按数据指定的命中修正。不能在此层写角色名、角色基础数值、特定技能的固定倍率。

`runtime-buff-engine.mjs` 只消费已确认的属性、数值、层级、分组与互斥策略；`runtime-buff-definitions.mjs` 保存已核实的共享状态定义和法术数据。列入定义不代表每个角色都拥有该法术；可用项由当前角色资料决定。未知分组不可冒用已有组。

`character-combat-rules.mjs` 与现有角色资料保存专属规则。洛琪希的冰魔法命中×2、单段×0.6、限定特殊魔法类型等必须绑定角色与来源，不是所有角色或所有双刀的默认值。其个性中的 Boss 特攻也不能自动赋予其他角色。

读取器记录客观观察；网页计算与预测不得回写成读取器实测。
