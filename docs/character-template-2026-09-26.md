# 艾莉丝接入与共用角色模板

用户要求：艾莉丝·格雷拉特按当前洛琪希·米格路迪亚·格雷拉特的做法接入；后续角色暂时沿用此模板，共同功能更新时全部角色同步。沿用原 Site、原 URL、原始技能 ID 和存档。

## 共同实现

- `dist/character-page.mjs` 是所有角色页的唯一计算器界面入口。245、259、260 都引用它，由它创建伤害计算器按钮与弹窗，并使用同一桥接模块。
- `dist/character-template.mjs` 注册各角色的规则、默认攻击属性、装备映射与条件。`collectCharacterSources` 同时供角色基础计算器和独立伤害计算器使用，防止两处来源收录不一致。
- `damage-calculator.html`、`entry-workflow.mjs`、`unified-calculator.mjs`、`scenario-bonus-summary.mjs`、配装 `app.js` 继续共用。圣物添加、角色自带技能总览、按当前攻击条件的伤害与上限汇总、两级详细、通用技能确认和加护隐藏但参与计算均沿用 v158。
- 所有共同修改必须改共用模块；不得按角色复制整套页面交互。新角色在注册表配置数据，静态页面引用共用入口，并在具有完整角色规则时启用 `data-rule-calculator`。
- 245 的旧基础加成数据未在本轮重新拆分，保留其既有实现；共用计算器入口与确认／配装界面已同步。不能据此宣称其专属数值适配已经补齐。

## 艾莉丝数据

`eris-rules.mjs` 保留原页面 43 个个性、专属、通用、超越、装备来源的 ID、名称和完整描述。另收录两个有明确数值的招式来源：波瑞阿斯拳暴击率 +20%，无声之太刀上限 +300,000，仅对各自招式生效。

默认特技参照攻击力、物理、无属性；不得继承洛琪希的冰魔法、法強或专属分段倍率。命中数、倍率和技能修正继续以读取器与已有手填资料为准，不凭页面描述生成。

单武器与剑条件分开：未装备剑不获得剑类增幅；双武器不获得单武器效果。普通物理词条仅用于普通攻击／特技，原文明确包含超必杀的词条才进入超必杀。

“一天真刃之极意”对基础“一天真刃·二之型”的 +50% 增幅，必须有对应基础技能启用；取消基础技能同时取消对应 +15% 伤害／+15,000 上限。概率暴击分支由条件 BUFF 与暴击共同控制，按已触发的最大数值试算，不能称为概率平均值。

原文“服装”保留展示，装备计算类型归一为“衣服”，以正确计算服装自身防御力与魔抗 +50%。专武开关只切换剑，不包含服装。

最近敌人、至少两人全员存活、敌人正在攻击、自身异常这四个艾莉丝条件放在现有通用伤害改变区域，与基础条件采用相同字段；没有增加新状态分类页。条件开关不能改变别的条件或强制全选。

## 配装修复

原 `buildLoadoutReport` 在有一件未指定武器的配置上勾选具体专武时，会把武器数从 1 加到 2，错误关闭单武器加成。现在先填已有空缺武器位，只有超出已有武器位时才增加数量。此修复共用于所有角色。

专武勾选时固定属性和伤害词条一起进入报告，关闭时一起退出。角色自带、额外通用技能、圣物和账户加护仍按原来源 ID 去重。

旧的未核对艾莉丝缓存报告会通过现行页面与保存的规则重新读取；手动确认报告、草稿、停用项和配装不被无条件清空。角色页和独立计算器都标记 `characterTemplateRevision: 1`。

## 仍需证据的数值

以下不补猜，不代表通用技能标签缺失；可通过读取器或原有手动确认入口采用实际值：

1. “你要干什么！”激昂期间按攻击力计算伤害／上限：需要当前战斗攻击力以及每 1,000 的结算／取整证据；“激怒”的数值原资料也没有。
2. “自动EX勇气”：原资料没有记录准确属性数值。
3. “沉睡的狮子”：攻击力 +100% 已知，但与其他攻击力 Buff 的原生叠加分组尚未记录，不能作为常驻面板 +100% 强行叠加。

饰品属性翻倍保留说明，当前页面没有具体饰品固定属性，不能凭空补入面板。此类保留项不应被写成“艾莉丝所有机制均已验证”。

## 验证与保护

`tests/character-template.test.mjs` 从现有角色页面提取来源，验证原文与 ID、两角色规则隔离、保存的手动修改、专武属性与词条联动、服装独立、技能依赖、条件开关、招式限定以及计算不中断。

本轮保护层基于 v158 提交 `6f847fc2ae8a27842779a30867feebdb5268f5f5`：`character-template-preservation-2026-09-26.json`。旧保护层不改写，回滚比较时先剥离本轮精确变更。

本环境没有可运行的浏览器内核；Node 回归和静态结构检查不称为手机／浏览器视觉实测。

全量 Node 测试：458 项，454 通过、4 项旧失败。旧失败仍为 `effect-totals` 特攻汇总、`reader-bonus-decoder` 43/44、`roxy-rules` 必杀物理范围与混合范围；没有新增失败。艾莉丝新增 7 项集成回归全部通过，历史分类／保护检查也通过。
