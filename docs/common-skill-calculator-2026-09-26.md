沿用原 Site `appgprj_6ab13ba277b881919538217cd5e376dc`，不重新建站，不改变受众。

- 普通技能列表 `index.html` 不展示标签、判断状态或标签说明，也不能编辑分类／标签。

- 通用技能应能进入伤害计算，但“分类已经完成”不等于未知数值和公式可自动采用。

## 已实施

普通列表恢复为名称、效果、评价、添加；分类列只读。保留原搜索、补充说明、名称／效果／评价编辑、SC、自带技能、已保存配装与所有原 localStorage 键。未删除原用户保存的分类名称，仅禁止继续编辑。

新增 `common-skill-catalog.mjs` 与 `common-skill-rules.mjs`：按稳定 ID、别名 ID 和完整描述匹配全部 935 条通用技能。修改效果文字不会继承官方数值。改名但未改描述且有稳定 ID 的技能仍可识别。

转换规则由 `scripts/compile-common-skills.mjs` 和 `scripts/build-common-skill-rules.mjs` 生成；不在页面里用名称模糊匹配百分比。旧 181 条基础属性规则、已核对的角色规则、读取器采样和用户明确保存的规则优先，不重复计算属性。

本轮通用片段目录有 611 条可执行规则、245 条待确认规则（这里统计的是规则，不是技能）。包括物理／魔法／特技／必杀／普通攻击、属性、Boss、装备、暴击、特攻、固定上限与单手替换上限、背后／浮空／异常／气绝或Break条件。来源相同的跨分类片段只保留一份。

二刀流按完整原文输出一个组合分段规则：实际装备两把武器时，物理命中 ×2、每段 ×0.6；不自动装备武器、不直接写作增伤 ×2，也不擅自决定分段结算位置。

种族条件读入当前目标种族，支持多种族任一匹配且只计一次；没有种族资料时提示待确认。伤害页增加种族核对选项和气绝状态，气绝触发相关增伤但不自动套用 Break 降防。背后、浮空、异常和弱点使用本次战斗输入。

旧存档中机器生成的空白“未识别”通用技能可以重新匹配；手动禁用、已确认规则与数值不会被覆盖。移除技能后相应增伤、上限和属性随之消失。

## 仍不能自动计算的情况

未确认公式、随机区间、人数／距离／时间等动态曲线、尚未接入的特殊触发与 Buff 叠加机制，不采用最高值，也不当作常驻增伤。配装区明确列出未计入的效果及原因。

队伍条件已分配在 `tagDetails.effectConditions[].effectBinding` 中；适配器读取该位置并保留谓词，不因为没有独立队伍分类而丢失条件。缺少实际队伍状态时暂不计入。目标易伤类减益也不能自动假定已经触发。

回复、吸血、来袭减伤、格挡、移动和奖励等非本次主攻击乘区不转换为增伤；独立追击、反击及部分参照计算还需对应的计算模型。不会因此倒退分类页的完成状态。
