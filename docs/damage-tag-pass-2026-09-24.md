# 伤害增加标签：第八轮，按用户纠正后的范围

## 必须沿用的分类规则

用户明确纠正：要把增伤描述理解为完整词条。“对Boss增加伤害”应归Boss增伤，不能拆掉“对Boss”后贴“伤害增加”。对空中敌人、属性等限定同理。这是分类语义规则，不是单纯把条件放入待判断栏就能解决。

因此本轮“伤害增加”仅指自身整体造成伤害增加。属性增伤、指定攻击类型增伤、对特定目标／种族／敌人状态的增伤，以及背后、特攻、弱点等限定增伤不纳入。敌方受到伤害增加属于易伤，也不纳入。后续继续一次一个标签，由用户指定，不自行同时创建Boss、属性或空中增伤标签。

自身整体增伤可以由队伍、自身装备、时间或连续Hit等条件启用；例如用户给定的“阵形：进击的奥尔达纳”。这些启用条件及并列效果仍需后续标签覆盖，未全部完成前仍是部分判断。
