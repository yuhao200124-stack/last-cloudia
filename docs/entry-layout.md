# 读取资料与伤害计算界面

主页面顺序为：只读角色六维（附加护后数值）、读取报告、招式与参数。六维与候选加成核对是同一计算器内独立视图，返回时保留填写状态。原基础候选横幅与种族复选列表不再显示。

## 读取边界

- 当前 v0.35 `BattleEntryReport.json` 可提供 `bosses[].stats.defense/mind`、`resistances` 六抗性。
- 当前文件中的 `race` 为 null，且没有技能参数；页面如实显示缺失，不从 Boss 名字推断。
- `battle-entry-data.mjs` 支持可选结构化 `units[].skills[].parameters`。只匹配唯一确切招式名、已绑定的游戏 skillId，或明确 normal 槽位；页面 magic-2 等序号不当作游戏 ID。
- `parameters` 支持 coefficient、skillPercent、skillAdd、skillPostAdd；命中段数始终由用户填写。
- 可选 processes 解码仅支持已核对的 process10001/10101/10103 同参数布局，process30401 是已知非伤害补充。未知处理、混合攻击、不同段参数不自动合并。
- 自动读值不持久化为手填值。用户主动修改的字段按招式保存；分段参数另按招式与单/双武器保存。换报告时未手改的缺失字段清空。

## 条件与采用值

- 本次特攻开关通过 killerOverride 覆盖触发状态，保留基础特攻倍率与已确认的特攻增伤词条各自入口，避免重复加入。
- Break 沿用已有防御倍率，并重新筛选已采用的 Break 词条。
- 双刀只影响伤害计算，配装与面板保持原设置；通用双刀和角色专属魔法双段分开判定，不把所有魔法、必杀统一乘 2×0.6。
- 完整候选与逐项决定都保留。改变条件后复用已有决定；已配置的模式技能随开关联动，新增或数值改变的普通词条仍需确认。
- 每次确认替换上一批导入效果，保留手工新增条目；读取器最终六维不再次乘网站属性加成。

## 汇总核对与删除（2026-09-24）

- 导入并选定角色后，有有效读取值的六维默认选“读取器”；缺值保留待选择。用户改成网站或手填后，普通重算不覆盖其选择。
- 六维下方按 `type / target / unit` 分组显示伤害、上限和暴击率词条。冰伤、冰魔法伤害、普通魔法伤害及Boss伤害分别合计；固定上限与百分比上限分开。这些是词条合计，不是把伤害公式各层合成一个百分比。
- 读取器一侧独立汇总已识别且符合当前条件的配置。优先使用已解码条件；已知元素配置1050450仅在完整条件签名一致时复用。显式对应来源若借用网站条件，会在来源明细标注。未识别/缺失显示“未读到”，不作为0。
- 当前真实v0.35报告的项目多为candidate；即使数值相同，也不声称已逐段生效或捕获全部加成。部分数据显示候选小计。只要存在已解析且符合当前条件的读取器来源，就可明确采用该组读取器数据；数值差异、网站来源缺少对应不再锁住选项。采用后逐条导入实际读取来源；缺读的已配置模式技能可按下面的模式规则补入，普通网站来源不叠加，原始读取小计不变。
- 原逐条核对表默认折叠。明细删除按来源ID、规则ID、效果索引和语义定位，只排除选中的效果；不删除角色资料或读取原始记录。相同复合效果（如知识之壁同时加双防）会同时影响对应属性。
- 删除固定装备属性仅把该项贡献排除，不等于卸下装备，也不误报其他装备自身强化缺失。网站面板、汇总、最终采用效果一起重算。
- 删除记录按角色保存在浏览器，重新导入/切换招式后仍保留；可在“已删除的加成”恢复。点击计算器重置才清空。展开中的明细在重算后保持展开。

## 部分读取的整组采用（2026-09-24）

- `reader-group-review.mjs` 独立保存整组读取选择。最终核对时临时排除对应网站行，再按来源逐条加入读取效果，保留暴击限制、暴击率阶段和角色归属。原有逐条选择保持兼容。
- 读取器独有来源和补充加成按读取 ID 去重；整组已采用的补充行显示已计入，不重复添加。
- 明确删除的对应读取项不参与计算，原始读取小计不修改；存在排除项时额外显示实际采用小计。精确对应到某一操作的删除不影响同技能的其他操作。
- 组选择按报告内容指纹及角色保存。批准的来源在条件变化后可取有序子集；新增来源、数值或执行顺序改变需重新选择，不悄悄改用网站。

## 战斗模式与显示（2026-09-24）

- 暴击、特攻、满血与 break 是通用条件开关；勾选后启用符合角色、装备、攻击类型等条件的对应技能及增伤、上限，关闭时一并移除。不能仅凭拥有特攻词条就计入未触发的特攻上限。角色专属机制仍由角色规则限定。
- 暴击资格技能附带的固定上限随技能启用，例如冰魔法暴击技能的 +2000；明确写为暴击伤害或暴击上限的效果只进入暴击分支，不污染普通伤害。开关不表示最终暴击率为 100%。
- 整组采用读取器时，已对应模式效果使用读取值；缺读但已配置的模式技能可用网站值补入，采用栏简短标注模式及补入值。反复切换不重复计入，明确删除或排除的效果不恢复。
- 同来源的独立效果保留各自条件，不能把常驻、满血或暴击限制合并。旧选择升级保留原批准顺序；模式项可插入，顺序冲突仍需重选。
- 面板及加成核对共用四列宽度、数字格式。结果卡的每段上限位于“全为普通命中时”上方，文字与数值加大；普通与暴击上限不同时分别显示。
