# 魔法伤害增加标签：第七轮

## 范围与全库核对

用户指定“下一个魔法伤害增加的”。继续一次一个标签，从全部935个唯一技能查找，使用原站现有原文、补充说明和已核对的关联效果，不重建网站，不改原技能文字。

本轮纳入明确的攻击魔法增伤，包含指定属性、科学类攻击魔法、装备、Boss、弱点、空中敌人、特攻触发、队友配对、复活、现实时间和随参照量变化的魔法增伤。魔力属性、MP上限、咏唱、治疗、魔法暴击资格、赋予特攻、伤害上限和减伤均分开。未限定魔法的通用／属性通用伤害沿用物理轮范围，留待各自标签。

全库检索163条魔法／法术／科学／咏唱／信仰相关项，另以威力、增幅、伤害等扩展检索597条。935条来源指纹与此前完整阅读的原文一致；分类独有的2026和2028也在审计中。2028仅增加魔法上限，本轮排除。

- 魔法伤害增加59个，未纳入876个。
- 复用9条旧记录：305、593、1066、241、658、754、1060、1366、1507；新建50条共享记录。
- 59条均为部分判断：仍有其它效果、条件或机制未完成，不能因为魔法增伤已识别就标成完整。
- 累计349个唯一技能：完整44、部分305、无法判断0。
- 前六类数量和完成数不变：攻击力87（14／73），防御力70（9／61），生命力25（15／10），魔力51（12／39），MP8（8／0），物理伤害增加130（0／130）。括号为完整／部分。

## 片段覆盖与边界

59个新标签只覆盖魔法增伤effect片段，不覆盖任何condition片段。既有技能保留稳定ID、原片段ID、原有标签及说明。305从零开始的文明追加science-magic-condition，补足此前尚未独立拆出的“仅限科学类攻击魔法”；原Wave和最多10次条件保留。

- 杖高阶增幅241：物理与魔法增伤都已覆盖，装备法杖条件仍待完成。
- 作战行动1066：攻击力、魔力参照及物理、魔法两个增伤分支均已贴标签；开场判断、比较条件仍待完成，不能把两分支同时计入。
- 斗智转轮593：沿用攻击力参照标签，新增魔法增伤标签；攻击力与增幅的换算公式仍待确认。
- 元素系列保留属性条件，超阶系列另保留魔法伤害上限。伤害上限不等于实际伤害增加。
- 魔导光环185、与帕克的契约380：分别保留MP消耗增加50%／25%，不算MP上限标签；380仍有冰属性条件。
- 神式560：前30秒限制的是魔法使用；不能凭这段文字推导50%增伤只持续30秒，也不归成40秒开场Buff。
- 灵魂狩猎690、英灵凭依1060：分别保留友方战斗不能／复活触发及40秒Buff、同类型只能计一项的机制。
- 艾奇德娜的试炼1812：自身易伤减益持续20秒，魔法增伤在开场20秒后生效；不能把增伤也写成持续20秒。
- 男人的自信2016：开场魔抗减益与随时间提高的魔法伤害分开。40秒是达到最高30%的时点；中间换算关系仍待确认，不直接填满30%。魔抗减益持续时间原文未给出。
- 魔法连锁429、元素连击691：保留同魔法／同属性、叠加和重置机制，不无条件使用最高值；691保留10秒或改用其它属性时重置。
- 威斯普之刻227、阴影之刻228、光降圣夜242：现实时间条件不是Buff，且本页不按浏览器当前时间自动启用；光／暗属性另列条件。
- 魔法狙击895：原文明示攻击魔法已触发特攻时伤害+20%，纳入相关增伤片段，relation=magic-killer-damage-increase。它不赋予特攻资格；特攻条件及计算阶段待后续确认，不能直接并入普通魔法增伤池。仅赋予特攻的凝视者系列本轮不纳入。
- 十二支之力「魔」1233：龙类型追加与上限保留为其它效果，不误写成“自身已有龙类型”的触发条件。
- 暗影强化1479：不限属性的魔法伤害+15%与暗属性通用伤害+10%分开；魔法15%不限制暗属性。
- 圣诞派对1799：队伍指定类型人数、开场条件、特技增伤保留；各人数实际增幅未确认，不能直接假定每人5%。
- 疯狂魔法师1839：保留当前HP持续下降，不归成生命力上限减少。
- 信仰1754：本库现有神秘之力提供者没有明确魔法增伤，不把光属性通用伤害或魔法减伤误算成魔法增伤继承。
